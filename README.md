Untuk jalanin pastikan punya npm  
Jalanin:  
1. npm install          (Buat install package dan masuk di node_modules)  
2. npm run setup:env    (Buat bikin .env)  
3. npm run dev          (Buat nyalain semua)  
4. Buka browser ke portnya, normalnya "http://localhost:8080"  
  
Buat nyoba API pake postman nda perlu buka "http://localhost:8080"
